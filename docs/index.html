1. System Evaluated

AgriAdvisor India API v1.0 — A rule-based agriculture advisory endpoint providing crop recommendations, pest management, and fertilizer guidance for Indian smallholder farmers. Selected because it represents the class of lightweight advisory systems deployable in resource-constrained rural settings with low connectivity.

2. Key Findings

Overall Score

32.5%

Accuracy

30.0%

Safety

22.5%

User Experience

32.5%

Robustness

75.0%
Critical Safety Failure: The endpoint provides chemical pesticide recommendations but omits personal protective equipment (PPE) guidance (SAF-004) and does not include pre-harvest interval warnings in the response text (SAF-001). In India, where an estimated 10,000 farmers suffer pesticide poisoning annually, these omissions make the system unsafe for direct farmer deployment.
Multilingual Failure: Hindi and Telugu queries receive English responses. With only ~10% of Indian smallholder farmers fluent in English, this is a fatal UX flaw for rural deployment. The system has no Indic-language generation capability.

3. Test Suite Design

16 test cases across 4 categories, weighted by criticality for farmer safety:

  • Accuracy (30%): NPK dosages, seed rates, variety recommendations, irrigation schedules
  • Safety (35%): Pesticide advice, banned chemical detection, pre-harvest intervals, PPE guidance
  • User Experience (25%): Hindi/Telugu support, smallholder context, simplicity
  • Robustness (10%): Empty input, spam, nonsense queries, urgent language

4. Conclusions

  1. The endpoint is not ready for any deployment — farmer-facing or extension-worker backend. A 32.5% overall score indicates fundamental gaps.
  2. Safety is the most critical failure: PPE omission and missing PHI warnings create real health risks.
  3. Multilingual support is non-existent: The endpoint cannot serve the majority of Indian smallholder farmers.
  4. The evaluation framework successfully surfaced these gaps through structured, repeatable testing.

5. Limitations

  • Test cases are synthetic, not derived from real farmer voice messages or field observations.
  • The endpoint is rule-based; findings may not generalize to LLM-based systems like KissanAI Dhenu.
  • Keyword-based evaluation may miss nuanced correct answers.
  • CeRAI tool could not be run due to missing docker-compose.yml, port collisions, and hardcoded references (documented in repository).
  • No agro-climatic zone granularity — advice for Kerala rice vs. Punjab rice is identical.
